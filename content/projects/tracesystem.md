## 项目简介

**扫码溯源系统**是一套面向生产制造场景的全链路产品溯源管理平台。系统围绕「码」这一核心对象，覆盖从**产品模板与多级码规则配置**、**批量生码与导出**、**产线扫码父子关联**，到**任意层级码值检索与链路追溯**的完整业务闭环。

典型应用场景包括白酒、食品、日化等需要**多层级包装**（瓶 → 盒 → 箱 → 垛 → 销售单元）的行业，以及强调**防伪防窜**的供应链追溯需求。管理端采用 React 单页应用，后端基于 Spring Boot 提供 REST API，数据持久化使用 MySQL。

## 业务模块

系统按生产流程划分为五大模块，侧边栏导航与实际操作路径一致：

| 模块 | 功能 | 说明 |
|------|------|------|
| **工作台** | 系统概览 | 运营看板：模板数、码总量、关联完成率；最近生码批次；各模板数据汇总；快捷入口 |
| **码体系配置** | 模板管理、层级规则 | 创建/复制/选用产品模板；为每层配置码长、子码容量、字符集、有序/无序生成策略 |
| **码数据生产** | 生码任务、生成结果 | 按模板与顶层数量批量生码；码量预估；批次列表与明细下载 |
| **生产执行** | 扫码绑定、绑定日志 | 父→子 / 子→父 两种扫码模式；工位级成功/失败统计；班次内操作日志 |
| **追溯分析** | 码值检索、链路追溯 | 支持任意层级码值查询；向上追溯祖先链、向下展开子码树 |

## 核心能力

### 1. 可配置的多级码体系

- 产品模板自由增删，支持**复制模板**快速复用规则
- 每层独立配置：**名称、前后缀、码长、子码容量**
- 生成模式：**无序码（随机）** 与 **有序码（流水）**，有序码通过 `code_level.seq_current` 持久化，生码时数据库悲观锁保证并发安全
- 字符集灵活：数字 / 大小写字母开关、排除易混字符（如 O/0）、自定义字符集；一键预设「纯数字」「数字+大写」等
- 生码前**码量预估表**：按层级递归乘算，例如 2 个顶层可展开为数百至数千枚销售级码

### 2. 批量生码与批次管理

- 选择产品模板、输入顶层码数量，一键提交生码任务
- 按层级递归生成完整码树，批次号唯一标识
- 生成结果页支持按模板筛选、刷新列表、**下载批次明细**（便于印刷厂或赋码设备导入）

### 3. 产线扫码绑定

- **父→子（装箱）**：先扫外箱/垛码，再扫内层单品码，适合标准装箱流程
- **子→父（补绑）**：先扫内码再扫外码，适合漏绑补录
- 大输入框 + **扫码即提交 + 自动聚焦**，适配扫码枪连续作业
- 实时展示本班次成功/失败次数与当前扫码模式

### 4. 全链路追溯

- **码值检索**：输入或扫描任意层级码，定位对应产品节点
- **链路追溯**：检索成功后跳转，展示上下游关联与子码展开，支撑稽查、召回与客诉定位

## 技术栈

**后端**：Java 17 · Spring Boot 3.2 · Spring Data JPA · MySQL 8 · RESTful API

**前端**：React 18 · TypeScript · Vite · Tailwind CSS · Zustand 状态管理

**基础设施**：Docker Compose 一键启动 MySQL；开发环境 Vite 代理 `/api` 至后端

## 数据模型

| 表 | 用途 |
|----|------|
| `code_template` | 产品模板（名称、描述） |
| `code_level` | 层级规则（排序、码长、子码容量、字符集、有序码计数器 `seq_current`） |
| `code_record` | 码记录（码值、层级、父码、批次、状态：已生成 / 已绑定） |

码值全局唯一（`uk_code`），通过 `parent_code` 建立父子关系，支持按批次、模板、层级多维查询。

## 架构与实现要点

1. **模板驱动**：同一套引擎适配不同行业包装结构（示例中为五层「五码防伪溯源」）
2. **递归生码**：按 `child_capacity` 自顶向下展开码树，批量写入 `code_record`
3. **绑定校验**：扫码关联时校验相邻层级关系，防止跨级或重复绑定
4. **追溯算法**：自任意节点向上遍历祖先链，向下 BFS/列表展开子码
5. **工位体验**：前端 Zustand 管理扫码会话状态；绑定日志会话级存储，适合单工位监控

## 项目价值

该项目将**码规则配置、数据生产、产线执行、追溯分析**串联为一体化后台，贴近真实工厂「先赋码、再装箱、后稽查」的流程。相比简单二维码生成工具，更强调**多级包装关系建模**与**生产现场可操作性**；技术选型轻量可部署，适合作为工业溯源、防伪码管理类系统的 MVP 或学习参考。
